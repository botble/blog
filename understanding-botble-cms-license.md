# Understanding Botble CMS License: Regular vs Extended

This guide explains how licensing works for Botble CMS products purchased on CodeCanyon.

## One License = One Website

According to [Envato's Standard License](https://codecanyon.net/licenses/standard), **one license can only be used for one end product** - meaning one website, whether it's a:

- Domain (example.com)
- Subdomain (shop.example.com)
- Subfolder (example.com/shop)
- IP address

**Need multiple sites?** You must purchase a separate license for each site/client.

> **Reference:** [How many licenses do I need for multiple end products?](https://help.market.envato.com/hc/en-us/articles/115005597526-I-want-to-make-multiple-end-products-with-the-same-item-how-many-licenses-do-I-need-to-buy)

## Development & Staging Sites

**Good news:** You can use Botble CMS on dev/staging/UAT environments **without activating a license**. This is NOT a license violation.

| Feature | Without License Activation |
|---------|---------------------------|
| All CMS features | Works |
| Plugins & themes | Works |
| Full functionality | Works |
| System Updater | Not available |
| Marketplace plugin installation | Not available |

The only limitations without activation are:
- **System Updater** - automatic updates from admin panel
- **Marketplace access** - installing new plugins from [marketplace.botble.com](https://marketplace.botble.com/plugins)

This allows you to freely develop and test before activating on your production site.

## Regular vs Extended License

The license type depends on **how your site makes money from end users**:

### Regular License

Choose Regular when your site **does NOT charge end users**:

- Free websites
- Blogs, portfolios, company sites
- Sites monetized through ads only
- Free membership/community sites

### Extended License

Choose Extended when your site **charges end users**:

- Monthly/yearly subscriptions
- Commission fees on sales
- SaaS platforms
- Pay-to-access features
- Any form of paid membership

> **Flexible approach:** Start with a Regular License and upgrade to Extended once you have paying users.

For full details, see [Envato Standard License Terms](https://codecanyon.net/licenses/standard).

## Quick Decision Guide

| Your Situation | License Needed |
|----------------|---------------|
| Building a company website | Regular |
| Personal blog | Regular |
| Free community site | Regular |
| E-commerce (no subscription fees) | Regular |
| SaaS with monthly fees | Extended |
| Marketplace taking commissions | Extended |
| Subscription-based membership | Extended |
| Multiple production websites | One license per site |
| Development/staging server | No activation needed |

## Summary

1. **One license = one production website**
2. **Dev/staging sites** work without activation (full features except updates & marketplace)
3. **Regular license** = site doesn't charge users
4. **Extended license** = site charges users (subscriptions, fees, SaaS)
5. **You can upgrade** from Regular to Extended anytime
