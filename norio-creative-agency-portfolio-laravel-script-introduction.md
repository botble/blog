A studio's website has an odd job. It has to look good enough to win work, and then get out of the
way so the work is what people remember. Most agency templates get the first half and forget the
second: the site is louder than the projects on it.

Norio is our new portfolio script built around the second half. It went live on CodeCanyon this
week. It is a full website for studios, agencies and freelancers, with its own admin panel and a
web installer, so you upload it, open your domain, pick a homepage and you have a finished site to
fill with your own work.

## Five ways to show your projects

This is the part that matters most for a portfolio, so it got the most layouts. There are five
project listing pages: a cinema style with large full-screen slides, a slider, a stack, and grids,
three of them with WebGL image effects on hover. Each project then has a detail page with the
brief, year, field, scope and a gallery.

![Four of the Norio project layouts, including the cinema slider and the WebGL hover grid](https://botble.com/storage/news/norio-project-layouts.jpg)

You do not need all five. Pick the one that suits the kind of work you do. Big campaign images
look best in the cinema layout, product UI and identity work read better in a grid.

## Motion that you can turn down

Norio uses GSAP for the reveals and scrolling (ScrollSmoother, ScrollTrigger, SplitText), and
Three.js for the fluid hero and the WebGL image effects. The demo is the best place to feel it,
move your mouse around before you read anything.

I know a lot of people are wary of this kind of site, so two things worth saying:

- **It respects reduced motion.** If a visitor has asked their operating system to reduce motion,
  Norio checks for it and drops the heavy effects. Smooth scrolling is always off for those
  visitors.
- **There are off switches in the admin panel.** Smooth scrolling, the custom cursor and the
  mouse-follow effects each have their own toggle. If a client wants something calmer, it is a
  setting, not a code change.

The navigation is part of that too. The menu opens as a full-screen overlay, and when you hover a
link its image appears beside it. You assign those images in the menu editor. On mobile you can
turn on a bottom navigation bar.

![The Norio overlay menu with an image preview beside the links](https://botble.com/storage/news/norio-overlay-menu.jpg)

## Build pages from blocks, not from code

There are 25 UI blocks: hero banner, projects, services, testimonials, pricing plans, call to
action, team, process steps, awards, partners, keyword ticker, FAQ, newsletter and more. Most have
several styles, 85 in total, and you pick a style from a visual preview instead of guessing from a
name.

You can place blocks in the normal page editor, or open the Visual Builder and drag them around
while the page previews next to you, with desktop, tablet and mobile views.

Logo, colors, fonts, five header styles and three footer styles are all in Theme Options, and a
page can override the site's header and footer if one page needs to look different.

![Norio Theme Options in the admin panel, choosing one of five header styles](https://botble.com/storage/news/norio-admin-theme-options.jpg)

The admin also covers the boring but necessary parts: portfolio projects and services, blog with
comments, team and careers with job applications, contact and project brief forms, newsletter,
media library, SEO and sitemap, multiple languages with RTL, users and roles, backups and an
activity log.

## What it is not

Better to know this before you buy:

- **No ecommerce.** Norio is for agency and portfolio sites. There is no cart or checkout. If you
  sell products, look at our ecommerce scripts instead.
- **Demo images are not included.** They are only for the demo. You replace them with your own work
  before going live, which you would do anyway.
- **The homepage preset is chosen at install.** Each preset installs its own demo content. On a
  live site you can rebuild the home page with the same blocks, but there is no one-click switch
  between presets.

## Requirements and installation

PHP 8.3 or higher, and MySQL 5.7+ or MariaDB 10.2+. Normal shared hosting with cPanel or
DirectAdmin is enough. It runs on Laravel 13 and Botble CMS, so developers get clean Laravel code if
they want to extend it.

connects the database and creates the admin account. If you would rather not do it yourself, we

## FAQ

### Is Norio a full script or just a design?

A full standalone script. The package has the website, the admin panel, the web installer and
every module shown above. There is nothing else to buy.

### Do I need to know how to code?

No. Pages, projects, posts, menus, colors, fonts and header and footer styles are all edited in the
admin panel.

### Can I turn off the animations?

Yes. Smooth scrolling, the custom cursor and the mouse-follow effects each have an off switch in
the admin panel, and visitors who prefer reduced motion get a calmer site automatically.

### Does it support RTL and other languages?

Yes. The site and admin support multiple languages, including right-to-left languages like Arabic.

### Can I switch homepage presets later?

Not with one click. The preset is picked in the installer. On a live site you can rebuild the home
page with the same blocks.

### How is it different from Orisa?

Both are for creative agencies. Orisa has five presets and leans harder into the playful side, like
the physics coming-soon page ([we wrote about it here](https://botble.com/orisa-creative-agency-theme-what-ai-cannot-design)).
Norio has three homepages, each in light and dark, puts more weight on how projects are presented,
and lets you switch the heavy effects off in the admin panel.
