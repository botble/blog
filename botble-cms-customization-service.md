# Need Botble Customized? Hire the Team That Built It

I'm Sang from Botble. Every week someone emails me a version of the same question: "your theme is almost exactly what I need, but I need it to do *this* one thing - can you build it?"

Until now the answer was a slow back-and-forth over email while I worked out whether it was a two-hour job or a two-week one. That was a bad experience for both of us, so we've made it a proper service with a page, a form and published prices.

It's live at [marketplace.botble.com/customize](https://marketplace.botble.com/customize).

## What we take on

Four kinds of work, which cover almost everything people actually ask for:

- **Custom feature and plugin development.** New admin modules, front-end features, API integrations, reports, workflows. Written as a plugin under `platform/plugins`, the same way we write ours.
- **Theme customization and design.** Restyle an existing theme, convert a static HTML template into a working Botble theme, rework layouts, add shortcodes, fix responsive and RTL problems.
- **Installation, setup and migration.** Server provisioning, deployment, queues and cron, SSL, email deliverability, and moving data across from WordPress, another Laravel app or a legacy database.
- **Upgrade, bug fixing and maintenance.** Version upgrades that keep your custom code intact, one-off bug fixes, performance work, and ongoing maintenance when you'd rather not own it.

If your job doesn't fit any of those, send it anyway. We'll tell you honestly whether it's something we should take on.

## What it costs

| Package | Price | Turnaround | Typical job |
|---|---:|---|---|
| **Quick Fix** | $99 flat | 1-2 days | One small change, a bug fix, config or setup help |
| **Feature Build** | from $399 | 1-2 weeks | A new plugin or admin module, a theme section, an API integration |
| **Full Project** | custom quote, from $1,500 | scoped per project | Multiple features, a migration, dedicated developer time |

Those are starting points, not the final number. Every job gets a fixed quote before we begin.

**Fixed, not estimated.** If we underscope the work, that's our problem, not a line item added to your invoice later. The only time the price moves is when *you* change what you're asking for - and then we quote the addition separately, before touching it.

Not included: hosting and server costs, third-party licences and API fees, and ongoing maintenance beyond the 30-day fix window. Anything like that gets named in the quote before you agree to it.

## How it works

1. **You send the brief.** Three honest sentences beat a padded requirements document. What you need, roughly when, roughly what budget.
2. **We reply within 1 business day.** Either a price and a delivery date, or the specific questions we need answered before we can give you one.
3. **We build it on a staging site.** You get a preview URL and can watch it take shape. Feedback during the build is expected - it's far cheaper than rework after delivery.
4. **Delivery, plus a 30-day fix window.** Full source, deployed to your site if you want us to. Anything broken in what we built gets fixed free for 30 days.

## Why buy this from us

**We wrote the CMS.** Botble CMS is our product. There's no learning curve, no reverse-engineering someone else's framework, and no agency guessing at how the core behaves.

**Your code survives core updates.** This is the part that costs people the most money when they hire elsewhere. A developer who doesn't know the platform will edit core files, and the next time you run the System Updater their work is gone. We ship features as plugins under `platform/plugins` and theme work on a renamed theme, so the updater never touches it. It's the same advice we give everyone in our guide on [upgrading Botble CMS with customization code](https://botble.com/how-to-upgrade-botble-cms-with-customization-code) - we just follow it ourselves.

**You talk to the developers.** No account manager relaying messages. The person answering your questions is the person writing the code, which is why quotes come back in a day rather than next week.

**The code is yours.** Full source, no obfuscation, no license callback. Modify it, deploy it, ship it as part of your own product. Happy to sign an NDA before you send the brief.

## A note on what we'll turn down

We say no to a fair amount of work, and it saves everyone time to say why up front.

We won't take a job where the honest answer is "an existing plugin already does this" - we'll point you at the plugin instead. We won't rebuild a theme from scratch when customizing an existing one gets you 90% of the way for a fifth of the price. And we won't quote a project where the requirements are still moving, because a fixed quote against a moving target is a fixed quote that turns into an argument.
